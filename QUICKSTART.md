# Quick Start Guide - Proxmox Cluster Dashboard

## 5-Minute Setup

### 1. Upload Files
Upload all files to your web server directory:
```bash
/var/www/proxmox-dashboard/
```

### 2. Create Your clusters.json
Rename `clusters.json.example` to `clusters.json` and edit with your clusters:
```bash
cp clusters.json.example clusters.json
nano clusters.json
```

### 3. Create Status Script
Create `/usr/local/bin/proxmox-status.sh`:
```bash
#!/bin/bash
# Your script to query Proxmox and generate status.json
# See README.md for detailed examples
```

Make it executable:
```bash
chmod +x /usr/local/bin/proxmox-status.sh
```

### 4. Setup Cron Job
```bash
crontab -e
# Add: * * * * * /usr/local/bin/proxmox-status.sh
```

### 5. Test
Open in browser: `http://your-server/proxmox-dashboard/`

## Key Features

### Search
- Press `/` to focus search
- Search clusters, nodes, or VMs
- Filter by type using buttons

### Filters
- Click "Filters" button
- Select status, type, region, version
- Click "Apply"

### Statistics
- Click "Show Statistics Dashboard"
- View charts, health score, regional stats
- Auto-updates when data refreshes

### Export
- Click download icon in header
- Choose CSV, JSON, or HTML format
- Share reports with team

### Dark Mode
- Click moon/sun icon in header
- Preference saved automatically

### Auto-Refresh
- Enable checkbox near "Last updated"
- Refreshes data every 60 seconds
- Pauses when tab is hidden

## Troubleshooting

**Problem**: No data showing
**Solution**: Check that clusters.json and status.json exist and are valid JSON

**Problem**: Nodes showing offline
**Solution**: Verify node names match exactly between files

**Problem**: Search not working
**Solution**: Clear browser cache and reload

**Problem**: Charts not displaying
**Solution**: Check internet connection (Chart.js loads from CDN)

## Customization

### Change Colors
Edit `styles.css` and modify `:root` variables:
```css
:root {
  --link: #0ea5e9;  /* Change primary color */
  --online: #10b981; /* Change online status color */
}
```

### Change Refresh Interval
Edit `config.js`:
```javascript
autoRefreshInterval: 60000, // Change to 30000 for 30 seconds
```

### Adjust Alert Thresholds
Edit `config.js`:
```javascript
thresholds: {
  cpuCritical: 90,  // Change to 95 for 95%
  memoryCritical: 95
}
```
